# TradeFlow AI

**AI-assisted cross-border payment preparation for SMEs.**

TradeFlow AI is a buildathon prototype that helps Nigerian SMEs prepare and review international vendor payments funded in NGN.

## Features

- Business workspace and vendor management.
- Payment preparation for USD, GBP, EUR, CAD and GHS.
- NGN funding, illustrative FX and fee calculations.
- Payment previews and transaction history.
- Rule-based invoice text extraction.
- Vendor and currency consistency checks.
- Explicit human confirmation of simulated payments.

## Technology

Python 3.13, FastAPI, Pydantic, SQLAlchemy, PostgreSQL, Redis, Alembic, HTML, CSS, JavaScript, Pytest and Docker Compose.
